# Анализ эффективности маркетинговых кампаний и клиентской базы

## О проекте

Итоговый аналитический проект по данным магазина спортивных товаров.

Цель проекта — подготовить и очистить данные о клиентах и покупках, оценить эффективность маркетинговой кампании, сегментировать клиентскую базу и построить модель склонности клиента к покупке.

## Что было сделано

- загрузка данных из SQLite;
- проверка качества и очистка данных;
- восстановление пропущенного пола клиентов с помощью бинарной классификации;
- построение клиентской аналитической витрины;
- исследовательский анализ данных;
- оценка эффективности первой маркетинговой кампании с помощью A/B-теста;
- кластеризация клиентской базы;
- построение модели склонности клиента к покупке;
- подготовка бизнес-рекомендаций;
- оформление итогового аналитического отчёта и презентации.

## Масштаб данных

В исходной базе использовались три таблицы:

- покупки — **786 260 строк**;
- персональные данные — **89 241 строка**;
- коэффициенты персональных данных — **104 989 строк**.

После подготовки была сформирована клиентская витрина на **104 437 клиентов**.

## Ключевые результаты

### A/B-тест маркетинговой кампании

В эксперименте участвовали **9 944 клиента**:

- контрольная группа — 4 960;
- тестовая группа — 4 984.

По сравнению с контрольной группой в тестовой группе:

- выручка на пользователя выросла на **18,61%**;
- количество покупок на пользователя выросло на **25,00%**;
- средний чек покупателей снизился примерно на **6,10%**;
- конверсия снизилась примерно на **4,19 п.п.**

Различия по рассмотренным метрикам были статистически значимыми при уровне значимости 0,05.

Персональное предложение стимулировало более частые покупки и увеличило выручку на пользователя. Перед масштабированием кампании рекомендуется дополнительно оценить влияние скидок на прибыль и маржинальность.

> В контрольной группе была зафиксирована конверсия 100%. Это необычная особенность сформированной выборки и ограничение, которое необходимо учитывать при интерпретации результатов.

### Сегментация клиентов

Для кластеризации использовались признаки, характеризующие демографию и покупательское поведение:

- возраст;
- количество покупок;
- общая сумма покупок;
- средний чек;
- число уникальных товаров;
- количество активных дней;
- доля покупок со скидкой;
- recency;
- предпочтения по товарным категориям.

Для подготовки и моделирования использовались:

- `log1p`;
- `StandardScaler`;
- `KMeans`;
- метод локтя;
- silhouette score.
