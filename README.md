# Анализ эффективности маркетинговых кампаний и клиентской базы

## О проекте

Проект посвящён анализу эффективности маркетинговых кампаний и поведения клиентов на основе данных интернет-магазина.

Основная цель — подготовить данные, исследовать ключевые показатели, определить наиболее эффективные клиентские сегменты и маркетинговые активности, а также сформулировать рекомендации на основе результатов анализа.

## Задачи проекта

В рамках проекта были выполнены следующие этапы:

- загрузка и первичная проверка данных;
- очистка и предобработка данных;
- исследовательский анализ данных (EDA);
- анализ клиентской базы;
- анализ эффективности маркетинговых кампаний;
- проверка статистических гипотез;
- A/B-анализ;
- сегментация клиентов;
- применение методов машинного обучения;
- визуализация результатов;
- формирование бизнес-выводов и рекомендаций;
- подготовка итогового аналитического отчёта и презентации.
